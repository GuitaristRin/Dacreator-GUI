# DACreator

为头文字D：激斗设计的Python程序，可以自动爬取arcadezone网页的计时赛成绩，生成易于阅读的表格，并记录历史数据追踪进步。

B站演示视频：<https://www.bilibili.com/video/BV13SFWzTEnv/>

---
## ✨ 最新特性 - v2.1.2

🎴 **新功能**
- 简报成绩卡生成：集成 render.py 模块，支持一键生成包含玩家ID、地区、城市、店铺、计时赛记录、赛季回合、名声分数、车队信息等内容的精美成绩卡图片。
- 车队名称配置：在 GUI 设置页面新增“车队”输入框，方便用户填写车队信息，并同步写入 Player_ID.dat。

🐛 **修复**
- 配置文件格式：修正 Player_ID.dat 写入格式，确保 KEY = VALUE 格式（等号前后带空格），完美适配 spider.py 的配置解析逻辑，解决“未找到 ID 行”的报错问题。
- 线程导入错误：修复 CardWorkerThread 中函数未定义的问题，通过线程内动态导入和路径切换，确保 get_round_info、get_pride_info、get_team_info 等模块正常调用。
- 成绩卡生成稳定性：优化多线程工作目录切换，避免因路径问题导致资源加载失败。

## ⚙️ 配置文件
用文本编辑器编辑目录下的 **`Player_ID.dat`**，输入自己的信息：
```ini
ID = 你的用户名
SEASON = 5
VERSION = 2.1.1
```
| 配置项 | 说明 | 示例 |
|--------|------|------|
| `ID` | ArcadeZone用户名 | 高橋リンタ |
| `SEASON` | 赛季（1-10） | 5 |
| `VERSION` | 程序版本（自动维护） | 2.1.1 |

*也可直接在GUI的「设置」页面可视化配置以上参数*

## 🎮 使用方法
### 🎨 GUI版本（新版）
```bash
# 方式1：一键启动
双击 run_gui.bat
# 方式2：手动启动
python dacreator_gui.py
```
**GUI版本功能：**
| 页面 | 功能 |
|------|------|
| 🏠 **主页** | 选择工作模式、开始生成、查看进度 |
| 📋 **数据** | 查看历史记录、按赛道筛选、追踪进步 |
| 📦 **版本** | 检查更新、查看版本信息 |
| ⚙️ **设置** | 配置ID、地区、城市、店铺名、赛季 |
| ℹ️ **关于** | 版本信息、开发者列表、依赖库 |

### 🖥️ CLI命令行版本（core.py独立使用）
```bash
python core.py <模式参数> [选项] [CSV文件路径]
```
#### 模式参数（三选一，必须指定）
| 参数 | 说明 | 功能 |
|------|------|------|
| `--spider` | 爬虫模式 | 遍历所有赛道，获取完整成绩数据（含全国排名） |
| `--search` | 搜索模式 | 通过用户名快速搜索成绩（无全国排名） |
| `--localcsv` | 本地CSV模式 | 从已有的CSV文件生成图片 |

#### 可选参数
| 参数 | 说明 |
|------|------|
| `-d DIR, --dir DIR` | 指定图片保存目录（不指定则只保存原始CSV到raw目录，不生成图片） |

#### 使用示例
```bash
# 1. 爬虫模式：仅保存原始数据
python core.py --spider
# 2. 爬虫模式：保存原始数据+生成图片到指定目录
python core.py --spider -d ./output
# 3. 搜索模式：快速获取成绩并生成图片
python core.py --search -d ./成绩图片
# 4. 本地CSV模式：从已有文件生成图片
python core.py --localcsv 我的成绩.csv -d ./output
# 5. 查看帮助信息
python core.py -h
```

## 📊 数据文件格式
如果需要用本地文件生成图片，CSV文件需符合以下格式：
```csv
コース,ルート,タイム,タイム評価,記録車種,全国順位,記録日
秋名湖,左周り,2'27"760,EXPERT,CIVIC TYPE R (FL5) [HC],255位,2026/01/19
秋名湖,右周り,2'28"702,EXPERT,CIVIC TYPE R (FL5) [HC],121位,2025/12/21
...
```
| 列名 | 说明 | 示例 |
|------|------|------|
| コース | 赛道名称 | 秋名湖、妙義、赤城 |
| ルート | 路线方向 | 左周り、右周り、下坡 |
| タイム | 成绩时间 | 2'27"760 |
| タイム評価 | 等级评价 | ROOKIE ~ LEGEND |
| 記録車種 | 使用车辆 | CIVIC TYPE R (FL5) |
| 全国順位 | 全国排名 | 255位 |
| 記録日 | 记录日期 | 2026/01/19 |

## ⚠️ 注意事项
### 1. 关于rank数据库
用于判断等级的 `./assets/rank.csv` 文件中，部分数据由AI推算，可能与真实值有出入。  
如有准确数据，欢迎提交PR！
### 2. 首次运行
- 需要联网下载依赖包
- 启动脚本自动完成环境配置，约需1-2分钟
- 请耐心等待命令行窗口完成初始化
### 3. 历史数据库
- 数据库文件 `dacreator_history.db` 自动生成在程序目录
- 所有记录永久保存，不会自动删除
- 可手动备份或删除该文件重置数据
### 4. 命令行使用
- core.py CLI工具所有模式均会自动保存原始数据到raw目录
- 路径包含空格时，请用英文双引号将路径括起
- 确保对目标保存目录有写入权限
